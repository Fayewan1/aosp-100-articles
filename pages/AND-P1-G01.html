7. 常见问题与误区

7.1 误区

误区一：以为应用层就是「写 Activity 代码」那一层。 P1 讲的不是 API 用法，而是这些 API 背后框架做了什么。

误区二：以为这卷要按篇号顺读。 301、302、402 是独立支线，路径 A 可先读主干（101→102→201/202→401）。

误区三（看起来对其实是错的）：以为应用进程是系统直接创建的。 应用进程由一个已存在的 Zygote 进程 fork 而来；启动参数也不是派生之后才拿到——它由 Zygote 在 fork 之前就经命令 socket 读入并解析（ZygoteConnection.java 约 123/126 行），再随子进程继承。
